# Context: 私の立ち位置と考え方

私は、コンタクトセンターの現場で約5年半、<br>
「お客様」そして「販売店様」という“人”に向き合う仕事をしてきました。

日々の業務の中心にあったのは、
問い合わせ対応そのものだけでなく、
その裏側にある不安・焦り・状況を理解し、
**人としてどう寄り添うか**という視点です。

その一方で、社内ではDX化やAI活用にも取り組み、
技術によって業務を効率化・仕組み化する経験も積んできました。
ただし、私の中では一貫して明確な軸があります。

**「技術は主役ではない。主役は常に現場の人である」**

お客様とオペレーターがいてこそ技術は意味を持ち、
その逆は成立しない。
現場の負担を理解せずに導入される仕組みは、
長続きしないことを、私は何度も見てきました。

私は大学でコンピュータサイエンスを専攻し、
エンジニアとしての就業経験も持っています。
システムやデータ、AIの仕組みを理解した上で、
**それを「現場で使える形」に翻訳する立場**として仕事をしてきました。

顧客目線、オペレーター目線、そして開発・技術目線。
この三つの視点を同時に持ちながら、
現場にとって無理のない改善を積み重ねてきたことが、
私の最大の強みです。

本ポートフォリオでは、
高度な技術力そのものを誇示するのではなく、
**「現場をどう前に進めるか」**
**「人を主役にしたまま、技術をどう活かすか」**
という考え方を中心にまとめています。

派遣という立場であっても、
現場を理解し、仕組みを整え、次につながる形で残す。
そのスタンスで価値提供をしていきたいと考えています。
