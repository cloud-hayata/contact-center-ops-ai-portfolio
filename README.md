# Contact Center Operations × AI / BI / PMO Portfolio

本リポジトリは、  
**コンタクトセンター運営における業務改善・AI活用・データ活用を、  
現場目線でどのように設計・実行するか**をまとめたポートフォリオです。

技術そのものを誇示するのではなく、  
**「人を主役にしたまま、判断と改善を前に進める仕組み」**を  
どのようにつくるかに焦点を当てています。

---

## このポートフォリオで伝えたいこと

- 現場（オペレーター・管理者）を理解した上での改善設計  
- AIを魔法にしない、現実的で安全な活用思想  
- BIを「眺めるもの」ではなく「判断につなげる装置」として使う視点  
- 派遣という立場でも、**価値提供と意思決定を前に進めるPMOの役割**

単なるアイデア集ではなく、  
**実際に組織に組み込めるレベルの思考と設計**を意識しています。

---

## 想定する業務領域

- コンタクトセンター運営・業務改善  
- CRMデータ（問い合わせ履歴）の活用  
- AI（ChatGPT等）による整理・検知・要約  
- BIによる可視化・傾向分析  
- PMOとしての判断支援・エスカレーション設計  

※ 本ポートフォリオは特定の企業・システムを想定しない仮想事例です。

## このポートフォリオのスタンス

- AIに判断を丸投げしない  
- 人命・安全・顧客体験を最優先する  
- 見落としを「気合」ではなく「構造」で防ぐ  
- 現場の負担を増やさない  
- 指示待ちではなく、自ら動き提案する  

**人を中心に据えたサービスだからこそ、  
仕組みで人を守ることが重要**だと考えています。

---

## 最後に

派遣という立場であっても、  
単なる作業者ではなく、  
**判断を前に進める存在として価値提供を行う**ことは可能です。

本ポートフォリオは、  
そのために自分が何を考え、  
どのように動いてきたか、  
そしてこれからどう貢献できるかを示すものです。
